# Funke R. Yusuf — Portfolio

A lightweight, responsive static portfolio. No backend, database or build step is required.

## Preview locally
Open `index.html` directly in your browser, or run:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy
### GitHub Pages
1. Create a repository, e.g. `portfolio`.
2. Upload these files.
3. Settings → Pages → Deploy from branch → `main` / root.

### Vercel
1. Push the folder to GitHub.
2. Import the repository in Vercel.
3. Framework preset: Other.
4. Deploy.

### Netlify
Drag this folder into Netlify Drop, or connect the GitHub repository.
